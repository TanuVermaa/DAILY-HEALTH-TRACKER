# Fitness Tracker & Diet Planner CLI

A Python application for monitoring caloric intake, calculating daily energy expenditures, and setting diet plans based on personal weight goals.

## Features
- **BMR & TDEE Calculations:** Uses the Mifflin-St Jeor equation with exercise activity multipliers.
- **Custom Goal Planning:** Calculates required daily caloric deficit/surplus for target weight goals over chosen timeframes.
- **Macro Breakdown:** Displays optimal protein, carbohydrate, and fat splits ($30/40/30$).
- **Interactive CLI:** Input body metrics, log daily meals, log workouts, and check net balance in real time.
- **Unit Tested:** Built with test suites ensuring valid calculations.
